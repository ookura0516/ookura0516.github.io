1. 取得する情報

情報内容利用目的
端末の識別子端末から取得する ID（Android の端末 ID 等）解答履歴とメモを利用者ごとに区別して保存するため。広告配信（第3項）
解答履歴各問題の正誤、単語帳に入れた問題類似問題・単語帳機能の提供のため
メモ（任意）利用者が解答後に入力したメモメモの保存・検索機能の提供のため

当社は、氏名・メールアドレス・電話番号・位置情報・連絡先・写真を取得しません。アカウント登録は不要です。

2. 保存先

解答履歴とメモは、Google LLC が提供する Firebase（Realtime Database）に保存されます。通信は暗号化（HTTPS）されます。Google のデータ取り扱いは Google プライバシーポリシーに従います。

3. 広告

本アプリは Google LLC の広告配信サービス AdMob を利用して広告を表示します。AdMob は広告の配信・効果測定・不正防止のために、広告 ID 等の端末識別子や利用状況を取得することがあります。詳細は Google の広告に関するポリシーをご覧ください。端末の設定から広告 ID のリセットやパーソナライズ広告の無効化ができます。

4. 第三者提供

第2項・第3項に記載した Google LLC のサービスを除き、当社は利用者の情報を第三者に提供・販売しません。法令に基づく場合を除きます。

5. データの削除

解答履歴・メモの削除を希望される場合は、上記連絡先まで「丙種危険物アプリのデータ削除依頼」としてご連絡ください。確認のうえ、30日以内に削除します。

6. 児童のプライバシー

本アプリは13歳未満の児童を対象としておらず、児童から意図して個人情報を取得することはありません。
